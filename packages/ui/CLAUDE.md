# @pr-monitor/ui

Shared component library. Consumed by `@pr-monitor/www` and `@pr-monitor/extension`.

## Rules

- **No Next.js or Vite imports.** This package must stay browser-runtime-only — no `'use server'`, no `next/*`, no `vite/*`. The Node-only `encryption.ts` lives in `www`, not here.
- **GraphQL fragments are colocated with components** using `graphql` tagged templates. Run `bun run relay` (or `bun relay` from root) after editing any `graphql` block.
- **Artifacts in `components/__generated__/` are generated.** Never edit them; they're gitignored and regenerated by `relay-compiler`.
- **Singleton runtime deps are peer deps** (`react`, `react-dom`, `react-relay`, `relay-runtime`, `graphql`). Adding a new runtime dep that has its own React context goes in `peerDependencies`. Stateless utility libs (`clsx`, `tailwind-merge`) stay in regular `dependencies`.
- **Path aliases `components/*` and `utils/*`** are how things import each other. Don't use relative imports between files in this package.

## Layout

- `components/` — React components.
- `components/__generated__/` — Relay artifacts (gitignored).
- `data/schema.graphql` — GitHub's GraphQL schema. Refresh by re-downloading from GitHub.
- `utils/` — small browser-safe helpers.
- `tailwind-preset.ts` — Catppuccin color palette + extensions. Both apps' `tailwind.config.ts` consume it via `presets: [preset]`.
- `relay.config.json` — `relay-compiler` config. Paths relative to this file.
